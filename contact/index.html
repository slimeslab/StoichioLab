About this tool

StoichioLab is a small, self-contained precursor stoichiometry calculator built alongside the PiezoSCAN project for ABO₃ perovskite piezoelectric discovery. It runs entirely client-side (open index.html in a browser, no server or account required). It was originally ideated from ChemSolve's core idea, given a target composition, a set of precursors, and a total quantity, tell you exactly how many grams of each precursor to weigh out, but extended well beyond it.

Beyond that baseline, it adds a manual Mol%/Wt% target-composition toggle, DO-NOT-balance decomposition rules (carbonate/nitrate/hydrate groups), a doping-series batch mode for solving several compositions at once, a precursor autocomplete library, CSV/print export, named/shareable recipes, literature-reference lookup for the same composition family, and a persistent calculation history.
